\# SensitivityOS



SensitivityOS is an open-source contextual data sensitivity classification framework.



\## Core Innovations



\- Semantic sensitivity graph traversal

\- Context-aware sensitivity escalation

\- Community classifier registry

\- Explainable uncertainty reasoning

\- Fully local/open-source inference stack



\## Planned Stack



\- FastAPI

\- spaCy

\- Presidio

\- NetworkX

\- DuckDB

\- Ollama

\- React



\## Vision



Treat sensitivity classification as a community-governed knowledge problem instead of a proprietary black-box ML problem.
